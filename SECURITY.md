# Security Policy

## Supported Versions

Only the `main` branch is actively maintained. This project is in early
development (pre-audit) — there are no tagged releases yet considered
stable for production use.

## Audit Status

**This contract has not undergone a formal third-party security audit.**
It has been reviewed for common Merkle-airdrop pitfalls (reentrancy
ordering, double-claim protection, proof verification correctness,
admin fund-reclaim timing) but should be treated as experimental. Do
not deposit significant funds on mainnet without an independent audit.
